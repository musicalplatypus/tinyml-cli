**Threat Model (STRIDE Analysis):**

| Component | Spoofing | Tampering | Repudiation | Information Disclosure | Denial of Service | Elevation of Privilege |
|-----------|----------|-----------|-------------|----------------------|-------------------|------------------------|
| CLI Args | ✅ Sanitization | ✅ shell=False | ⚠️ Logging | ⚠️ Output | ✅ Timeouts | ❌ None |

```markdown
# mmcli Security Model

## Threat Model (STRIDE)

### CLI Arguments
- **Spoofing:** Mitigated by input sanitization (`_sanitize_input()`)
- **Tampering:** Mitigated by shell=False and argument arrays
- **Denial of Service:** Mitigated by timeout enforcement and input length limits

### File System Operations
- **Repudiation:** Mitigated by path validation (`_is_safe_path()`)
- **Information Disclosure:** Limited to project directory access only
- **Denial of Service:** Mitigated by file size limits

### Subprocess Execution
- **Elevation of Privilege:** Not applicable - runs as current user
- **Tampering:** Mitigated by input sanitization before subprocess call

## Attack Vectors

1. Command injection via CLI arguments
2. Path traversal via project path argument
3. Environment variable manipulation
4. Buffer overflow (prevented by length limits)

## Security Features Checklist

- [x] Input validation on all user-provided strings
- [x] shell=False for all subprocess calls
- [x] Absolute path resolution with validation
- [x] Timeouts on subprocess execution
- [x] Output size limits to prevent DoS
```

### Task 2: Create attack surface test suite

<action>Create `tests/test_attack_surface.py` with targeted security tests.</action>

```python
# tests/test_attack_surface.py (new file)
import pytest
from mmcli.cli import _sanitize_input, _is_safe_path
import subprocess

class TestInputSanitization:
    """Test input sanitization against various attack patterns."""

    @pytest.mark.parametrize("malicious", [
        ";rm -rf /",
        "| cat /etc/passwd",
        "`whoami`",
        "$(whoami)",
        "python -c 'import os; os.system(\"echo pwned\")'",
        "test;ls",
        "test && ls",
        "test || ls",
    ])
    def test_sanitize_blocks_command_injection(self, malicious):
        """Command injection patterns should be removed."""
        result = _sanitize_input(malicious)
        for char in [';', '|', '`', '$']:
            assert char not in result

    @pytest.mark.parametrize("path", [
        "/etc/passwd",
        "/var/log/syslog",
        "/root/.ssh/id_rsa",
    ])
    def test_sanitize_blocks_absolute_paths(self, path):
        """Absolute paths should be rejected."""
        # Note: _sanitize_input doesn't reject absolute paths directly,
        # that's handled by _is_safe_path
        assert not _is_safe_path(path)


class TestPathValidation:
    """Test path validation against traversal attacks."""

    @pytest.mark.parametrize("traversal", [
        "../../etc/passwd",
        "..\\..\\windows\\system32",
        ".....//.....//etc/passwd",
        "../" * 10 + "file.txt",
    ])
    def test_path_traversal_blocked(self, traversal):
        """Path traversal attempts should be blocked."""
        assert not _is_safe_path(traversal)


class TestSubprocessSecurity:
    """Test subprocess execution security."""

    def test_subprocess_shell_is_false(self):
        """All subprocess calls must use shell=False."""
        # This is verified by code inspection,
        # but we can check the implementation pattern
        import inspect
        from mmcli.cli import run_mmcli
        
        source = inspect.getsource(run_mmcli)
        assert "shell=False" in source or "shell = False" in source


class TestTimeoutEnforcement:
    """Test timeout enforcement on subprocess calls."""

    def test_timeout_prevents_hang(self):
        """A hanging subprocess should be terminated."""
        # This tests that timeouts are configured
        import mmcli.cli as cli_module
        assert hasattr(cli_module, 'SUBPROCESS_TIMEOUT') or \
               any('timeout=' in str(call) for call in cli_module.__dict__.values())
```

### Task 3: Add integration tests with malicious inputs

<action>Create integration tests that pass attacker-controlled input to CLI.</action>

```python
# tests/test_integration_security.py (new file)
import pytest
from click.testing import CliRunner
from mmcli.cli import cli


@pytest.fixture
def runner():
    return CliRunner()


class TestCLIWithMaliciousInput:
    """Test CLI behavior with potentially malicious inputs."""

    def test_command_injection_via_argument(self, runner):
        """Command injection in argument should be sanitized."""
        # Note: This test verifies the sanitization happens,
        # not that it's perfect (that would require endless tests)
        result = runner.invoke(cli, [
            "info", "-m", ";rm -rf /"
        ])
        # Should either fail with proper error or sanitize input
        assert "command not found" in result.output.lower() or \
               isinstance(result.exception, SystemExit)

    def test_path_traversal_via_project_flag(self, runner, tmp_path):
        """Path traversal attempt should be blocked."""
        malicious_path = str(tmp_path) + "/../../etc"
        
        result = runner.invoke(cli, [
            "analyze", "-i", malicious_path
        ])
        
        # Should fail with path validation error
        assert "invalid" in result.output.lower() or \
               isinstance(result.exception, SystemExit)
```
