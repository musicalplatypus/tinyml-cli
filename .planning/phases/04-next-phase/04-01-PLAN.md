## Objective

Implement fuzz testing framework using hypothesis to automatically generate test cases for input validation.

## Background

**Context:** Current tests use manually written test cases. Fuzz testing can automatically discover edge cases and boundary conditions that manual testing might miss.

**Motivation:**
- CLI accepts arbitrary user input
- Paths, filenames, and arguments have complex valid/invalid patterns
- Security vulnerabilities often appear at input boundaries

    """Hypothesis strategies for CLI input generation."""
    return {
        'basic': st.text(min_size=1, max_size=256),
        'alphanumeric': st.text(alphabet=st.characters(whitelist_categories=['Lu', 'Ll', 'Nd'])),
        'path_like': st.text(alphabet=st.characters(whitelist_characters=['a-z', 'A-Z', '0-9', '-', '_', '.', '/'])),

    """Generate random CLI argument values using hypothesis."""

        cli_input_strategies['basic'],
        cli_input_strategies['alphanumeric'],
        cli_input_strategies['path_like']

### Task 3: Add fuzz tests for input sanitization

<action>Create `tests/test_fuzz_sanitization.py` with fuzz-based tests.</action>

```python
# tests/test_fuzz_sanitization.py (new file)
import pytest
from hypothesis import given, strategies as st, example
from mmcli.cli import _sanitize_input

@given(st.text(max_size=2048))
def test_sanitize_does_not_crash(input_str):
    """Sanitize should never crash."""
    result = _sanitize_input(input_str)
    assert isinstance(result, str)

@given(st.text(alphabet=st.characters(whitelist_characters=[';', '$', '`', '|'])))
@example(";rm -rf /")
@example("$HOME;/bin/sh")
@example("`whoami`")
def test_sanitize_blocks_command_injection(input_str):
    """Malicious patterns should be removed."""
    result = _sanitize_input(input_str)
    # Check that dangerous patterns are stripped
    assert ';' not in result
    assert '$' not in result
    assert '`' not in result

@given(st.text(max_size=2048))
@example("a" * 1500)
def test_sanitize_enforces_length_limit(input_str):
    """Result should never exceed maximum length."""
    result = _sanitize_input(input_str)
    assert len(result) <= 1024
```

<verify>Run: `pytest tests/test_fuzz_sanitization.py -v --hypothesis`</verify>

<done>All fuzz tests pass with hypothesis strategy generation.</done>

### Task 4: Add fuzz tests for path validation

<action>Create fuzz tests for `_is_safe_path()` function.</action>

```python
# tests/test_fuzz_path_validation.py (new file)
import pytest
from hypothesis import given, strategies as st
from mmcli.cli import _is_safe_path

@given(st.text(max_size=256))
def test_path_validation_always_returns_bool(input_str):
    """Path validation should always return True or False."""
    result = _is_safe_path(input_str)
    assert isinstance(result, bool)

@given(st.text(alphabet=st.characters(whitelist_characters=['.', '/'])))
@example("../")
@example("../../")
@example("../../../etc/passwd")
def test_path_traversal_blocked(input_str):
    """Path traversal attempts should be blocked."""
    if '..' in input_str:
        result = _is_safe_path(input_str)
        assert result == False
```

<verify>Run: `pytest tests/test_fuzz_path_validation.py -v --hypothesis`</verify>
