**Phase:** 03

## Objective

Fix integration test failures caused by missing `tinyml_modelmaker` import in subprocess calls.

## Background

**Context:** Phase 2 completed basic command tests, but integration tests fail because they attempt to run `mmcli info` which internally executes Python code that imports `tinyml_modelmaker`.

**Evidence:**
```
tests/test_cli_integration.py::TestInfoCommand::test_info_lists_models[timeseries-generic_timeseries_classification] FAILED
AssertionError: mmcli info failed: ERROR: Cannot import tinyml_modelmaker:
ModuleNotFoundError: No module named 'tinyml_modelmaker'
```

## Analysis

### Root Cause

The `mmcli info` command executes a subprocess to query the tinyml_modelmaker registry:

```python
# Source: mmcli/info.py (lines 19-98)
_QUERY_SCRIPT = textwrap.dedent(r'''
import json, sys

module_name = {module!r}
task_type   = {task_type!r}

try:
    if module_name == "timeseries":
        from tinyml_modelmaker.ai_modules.timeseries import constants, training
    ...
''')

def _run_query(python_exe: str, script: str) -> dict:
    result = subprocess.run(
        [python_exe, "-c", script],
        capture_output=True,
        text=True,
    )
    return json.loads(result.stdout)
```

Tests don't mock this subprocess call.

### Solution Approaches

| Approach | Pros | Cons |
|----------|------|------|
| Mock subprocess in tests | Fast, deterministic | May miss real integration issues |
| Install tinyml_modelmaker as dev dep | Tests real behavior | Slower, environment-specific |

**Recommended:** Use unittest.mock to patch `_run_query()` calls.

## Implementation Plan

### Task 1: Add tinyml_modelmaker Mock Fixture

<action>Create a pytest fixture that mocks all tinyml_modelmaker subprocess calls.</action>

```python
# tests/conftest.py (add new fixture)
import pytest
from unittest.mock import patch, MagicMock

@pytest.fixture
def mock_tinyml_modelmaker():
    """Mock the tinyml_modelmaker registry query."""
    with patch("mmcli.info._run_query") as mock_run_query:
        mock_run_query.return_value = {
            "models": ["generic_timeseries_classification", 
                       "generic_timeseries_regression",
                       "generic_timeseries_forecasting",
                       "generic_timeseries_anomalydetection"],
            "devices": ["F28P55", "MSPM0G3507", "AM263"],
            "tasks": ["timeseries_classification"]
        }
        yield mock_run_query
```
