### Task 2: Add Windows path handling tests

<action>Create `tests/test_cross_platform.py` with platform-specific tests.</action>

**Note (cross-AI review):**
1. `sanitize_path` does not exist in mmcli; the function was `_sanitize_input`, which was removed in Phase 5 (`eb0a1bd`). Tests that depend on it are marked `skip` until 01-02 restoration completes.
2. `_is_safe_path("C:\\Users\\test\\project")` returns `False` on non-Windows hosts under the 03-02 revised implementation (anchored to cwd + `gettempdir()`, not OS prefix list). The Windows absolute path test is marked `win32` only.

```python
# tests/test_cross_platform.py (new file)
import sys
import pytest
import tempfile
from pathlib import Path

# _sanitize_input removed in Phase 5 — import guarded until 01-02 restoration
try:
    from mmcli.cli import _is_safe_path, _sanitize_input
    _SECURITY_FUNCS_AVAILABLE = True
except ImportError:
    _is_safe_path = None
    _sanitize_input = None
    _SECURITY_FUNCS_AVAILABLE = False

skip_security = pytest.mark.skipif(
    not _SECURITY_FUNCS_AVAILABLE,
    reason="_is_safe_path/_sanitize_input not yet restored (Phase 5 regression)"
)

@skip_security
@pytest.mark.skipif(sys.platform != "win32", reason="Windows absolute paths only valid on win32")
def test_windows_absolute_path_handling():
    """Windows absolute path handling — only tested on actual Windows."""
    assert _is_safe_path("C:\\Users\\test\\project") == True
    assert _is_safe_path("..\\..\\windows\\system32") == False

@skip_security
def test_relative_path_handling():
    """Relative paths under cwd should be safe on all platforms."""
    assert _is_safe_path("./project/data") == True
    assert _is_safe_path("../../etc/passwd") == False

@skip_security
def test_temp_dir_paths_allowed():
    """OS temp directory subdirs must be accepted (uses gettempdir(), not OS prefix list)."""
    tmp = tempfile.mkdtemp()
    assert _is_safe_path(tmp) == True
    assert _is_safe_path(str(Path(tmp) / "subdir")) == True
```

### Task 3: Add path separator normalization tests

<action>Add tests for path separator handling across platforms.</action>

**Note:** `sanitize_path` and `join_paths` do not exist in mmcli/cli.py. These tests are removed. Path separator handling is exercised indirectly through `_is_safe_path()` which uses `pathlib.Path.resolve()`.

```python
@skip_security
def test_traversal_blocked_regardless_of_separator():
    """Path traversal using any separator should be blocked."""
    assert _is_safe_path("../../etc/passwd") == False
    if sys.platform == "win32":
        assert _is_safe_path("..\\..\\Windows\\System32") == False

@skip_security
def test_empty_and_none_paths():
    """Empty strings should be rejected."""
    assert _is_safe_path("") == False
    assert _is_safe_path("   ") == False
```
