### Task 1: Set up Sphinx configuration

<action>Create Sphinx documentation infrastructure.</action>

```python
# docs/conf.py (new file)
# Note (cross-AI review): pin alabaster version in requirements; use dynamic year
import sys
import os
import datetime
sys.path.insert(0, os.path.abspath('..'))

project = 'mmcli'
copyright = f'{datetime.datetime.now().year}, Texas Instruments'  # dynamic — not hardcoded 2024
author = 'Texas Instruments'

extensions = [
    'sphinx.ext.autodoc',
    'sphinx.ext.napoleon',
    'sphinx.ext.viewcode',
]

html_theme = 'alabaster'
# Pin alabaster in docs/requirements.txt: alabaster==0.7.16
# Unpinned alabaster has broken API between minor versions.
html_static_path = ['_static']
```

Environment Variables
=====================

mmcli uses the following environment variables:

MMCLI_PYTHON
   Path to Python executable. Defaults to `python3`.

MMCLI_MODELZOO_PATH  
   Path to model zoo directory. Required for model recommendations.

MMCLI_MODELMAKER
   Path to tinyml_modelmaker installation. Required for info queries.

### Task 4: Add documentation CI/CD

<action>Create script to build and validate docs.</action>

```bash
# scripts/docs.sh (new file)
#!/bin/bash
set -e

# Install sphinx if needed
pip install sphinx sphinx-autodoc-generation

# Build HTML docs
sphinx-build -b html docs/ docs/_build/html

# Validate links
sphinx-build -b linkcheck docs/ docs/_build/linkcheck
```
