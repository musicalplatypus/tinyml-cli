## Objective

Fix E2E test failures caused by path validation rejecting `/private/var/folders/...` (macOS temp paths).

## Background

**Context:** E2E tests fail with "Invalid project path" errors when using `tmp_path` from pytest fixtures.

**Evidence:**
```
tests/test_e2e.py::TestDryRunE2E::test_dry_run_quantization_int_in_yaml FAILED
AssertionError: dry-run failed: ERROR: Invalid project path: /private/var/f...
```

## Analysis

### Root Cause

The `mmcli` tool validates project paths in `_validate_args()`:

```python
# Source: mmcli/cli.py (lines 105-127)
def _is_safe_path(path: str) -> bool:
    """Check if path is safe for project operations."""
    normalized = os.path.normpath(path)
    
    # Reject path traversal attempts
    if '..' in os.path.relpath(normalized, '.'):
        return False
    
    # Only allow paths under current directory
    if not normalized.startswith('.'):
        return False
    
    return True
```

This rejects `/private/var/folders/...` because it doesn't start with `.`.

### Solution Approaches

| Approach | Pros | Cons |
|----------|------|------|
| Update `_is_safe_path()` to allow temp dirs | Tests work as intended | Need to audit security implications |
| Use project-local temp dirs in tests | No code changes needed | Less realistic testing |

**Recommended:** Update `_is_safe_path()` to allow standard temp directory locations while still blocking path traversal.

## Implementation Plan

### Task 1: Update `_is_safe_path()` function

<action>Update `mmcli/cli.py` `_is_safe_path()` to allow temp directories.</action>

**Note (cross-AI review):** Do NOT use a hardcoded OS-specific prefix list (`/private/var/folders`, etc.) — this breaks on Linux CI and Windows. Use `tempfile.gettempdir()` resolved via pathlib, which returns the correct OS temp root on every platform.

```python
# mmcli/cli.py (modify _is_safe_path — once restored from Phase 5 regression)
import tempfile
from pathlib import Path

def _is_safe_path(path: str, base_dir=None) -> bool:
    """Check if path is safe for project operations."""
    if not path or not path.strip():
        return False
    try:
        resolved = Path(path).resolve()
        anchor = Path(base_dir).resolve() if base_dir else Path.cwd()
        # Allow paths under the working directory
        if resolved.is_relative_to(anchor):
            return True
        # Allow paths under the OS temp directory (cross-platform)
        temp_root = Path(tempfile.gettempdir()).resolve()
        return resolved.is_relative_to(temp_root)
    except (ValueError, OSError):
        return False
```

```python
# tests/test_cli_integration.py (add new test)
import tempfile
from pathlib import Path

def test_is_safe_path_with_temp_directories():
    """Temp directories should be safe — uses gettempdir(), not hardcoded paths."""
    tmp = tempfile.mkdtemp()
    assert _is_safe_path(tmp) == True
    assert _is_safe_path(str(Path(tmp) / "subdir")) == True

def test_is_safe_path_still_blocks_traversal():
    """Path traversal should still be blocked."""
    assert _is_safe_path('../../etc/passwd') == False
    assert _is_safe_path('') == False
```
