## Decisions Made

1. **Test fixtures approach**: Centralized fixtures in `conftest.py` rather than per-file duplication
   - Rationale: Consistency across test files, easier maintenance

2. **Mocking strategy**: Use `mock.patch.dict('sys.modules', {...})` for optional dependencies
   - Allows tests to run without requiring numpy/pandas installed

3. **Key name fix in analyze.py**: Changed `min_sample_length` to `min_seq_length` in `_analyse_files`
   - Rationale: Consistency with function naming (`_analyse_classes` uses `min_sample_length`, `_analyse_files` should use `min_seq_length`)
