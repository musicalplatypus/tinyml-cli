## Config File Format Reference

Based on mmcli/cli.py and builder.py, the YAML config structure includes:
- common section (target_module, task_type, target_device)
- training section (model_name, epochs, batch_size, etc.)
- compilation section (enable, model_path, preset)
- dataset section (input_data_path)

## Example Subcommands
1. train - Full training configuration
2. compile - Compilation-only workflow
3. run - Full pipeline (train + compile)
4. info - Query with module/task/device filters
5. recommend - Model recommendations with criteria
