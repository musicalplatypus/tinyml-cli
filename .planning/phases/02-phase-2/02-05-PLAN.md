## Environment Variables Reference

The following MMCLI_* environment variables should be documented:

1. **MMCLI_PYTHON** - Path to Python interpreter with tinyml_modelmaker
   - Default: 'python' or 'python3' found on PATH

2. **MMCLI_MODELMAKER** - Path to tinyml-modelmaker source directory
   - Defaults to the directory of run_tinyml_modelmaker.py resolved from the package itself

3. **MMCLI_DATASETS** - Override built-in datasets directory
   - Used by 'mmcli init' subcommand

4. **MMCLI_MODELZOO_PATH** - Path to tinyml-modelzoo repo root
   - Used by 'mmcli recommend' subcommand
