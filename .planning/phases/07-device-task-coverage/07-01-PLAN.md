# Plan 07-01: Add F28E12 Device + Audio Task Constants + Help Text

## Objective

Add the missing `F28E12` C2000 device to mmcli's `TARGET_DEVICES` list and introduce
`TASK_TYPES_AUDIO` so that `audio_classification` is properly enumerated throughout the CLI.

## Background

**Gap 1 — F28E12:** `tinyml_modelmaker.ai_modules.timeseries.constants.TARGET_DEVICES`
includes `F28E12`, but `mmcli/cli.py:TARGET_DEVICES` does not. Any user specifying this
device gets an argparse error before the pipeline runs.

**Gap 2 — audio_classification:** The `audio` module is in `MODULES = ["timeseries",
"vision", "audio"]` and the backend supports `audio_classification`, but `cli.py` has no
`TASK_TYPES_AUDIO` constant and the `--task` help text only lists timeseries and vision
tasks. Users have no way to discover the audio task type from the CLI.
