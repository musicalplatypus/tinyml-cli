# Plan 07-03 — Fix --task Help Text Wrapping (Audio tasks section invisible)

## Problem

argparse's `RawDescriptionHelpFormatter` preserves `\n` in `description`/`epilog` but NOT in argument `help=` strings. The `--task` help string in `_add_common_args` uses `\n` to separate "Timeseries tasks", "Vision tasks", and "Audio tasks" sections, but argparse collapses these to spaces and re-wraps at terminal width. This causes "Audio" to land at the end of the Vision tasks line and "tasks: audio_classification" to start the next line without its header — making the Audio tasks section visually invisible to users.

## Root Cause

`formatter_class=argparse.RawDescriptionHelpFormatter` on the `train`, `compile`, and `run` subparsers.

## Fix

Change all three to `formatter_class=argparse.RawTextHelpFormatter`. This formatter respects `\n` in ALL help strings (arguments AND description/epilog). The existing descriptions already use `\n` for manual formatting, so this is a safe swap.
