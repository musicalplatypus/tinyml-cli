### Task 2: Create progress helper module

<action>Create `mmcli/progress.py` with reusable progress bar functions.</action>

```python
# mmcli/progress.py (new file)
"""Progress visualization helpers for long-running operations."""

from typing import Optional, Iterable, Callable
from tqdm import tqdm


def create_progress_bar(
    total: int,
    desc: str = "Processing",
    unit: str = "it",
) -> tqdm:
    """
    Create a progress bar for long-running operations.
    
    Args:
        total: Total number of iterations
        desc: Description text shown before progress bar
        unit: Unit description for each iteration
        
    Returns:
        tqdm progress bar instance
    """
    return tqdm(
        total=total,
        desc=desc,
        unit=unit,
        dynamic_ncols=True,
        bar_format="{l_bar}{bar}| {n_fmt}/{total_fmt} [{elapsed}<{remaining}]"
    )


def track_progress(items: Iterable, desc: str = "Processing") -> Iterable:
    """
    Wrap an iterable with a progress bar.
    
    Args:
        items: Iterable to track
        desc: Description text
        
    Returns:
        Wrapped iterable with progress bar
    """
    return tqdm(items, desc=desc, dynamic_ncols=True)
```
