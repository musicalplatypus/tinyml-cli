# Plan 01-01: Core CLI Structure and Essential Commands

## Goal

Build a self-contained macOS CLI tool that drives tinyml-modelmaker training and compilation
from command-line arguments via subprocess dispatch. Delivered as a PyInstaller binary for
macOS (and later Linux/Windows).

## Problem

tinyml-modelmaker requires a complex Python environment (TensorFlow, ONNX, numpy, etc.) that
must be isolated from the calling process. Users need a native binary entry point that:
- Accepts training/compilation arguments from the command line
- Dispatches work to the tinyml-modelmaker venv via subprocess
- Handles YAML config file generation and override

## Architecture

**Key pattern:** CLI binary calls out to `MMCLI_PYTHON` (a separate venv) via `subprocess.run(shell=False)`.
This isolates TensorFlow/tinyml-modelmaker dependencies from the CLI binary itself.

```
mmcli binary → subprocess.run([MMCLI_PYTHON, runner_script, yaml_config]) → tinyml-modelmaker venv
```
