# Plan 10-04: PlatypusStudio Download Affordance

## Objective

Surface dataset downloading in the New Project sheet, so a user picking an unbundled dataset
gets an explicit "Download (54 MB)" step with progress instead of an unexplained failure.

**Different repository.** These paths are in `PlatypusStudio`, not `tinyml-cli`. Track the
work here because it is meaningless without 10-02, but land it as a separate commit in that
repo.

## Background

`NewProjectSheet` shells out to `mmcli init` to create a project from an example dataset.
Once 10-03 unbundles the large datasets, choosing `fan_blade_fault` will either block on a
silent multi-megabyte download or fail, depending on how 10-02's auto-fetch is configured.
Neither is acceptable in a GUI without a visible affordance.

The division of responsibility is deliberate: **mmcli owns the download, the app owns the
prompting.** mmcli is used headless and in CI and must work without a GUI, so the fetch logic
cannot live in the app. The app already invokes mmcli for every other operation, so calling
`mmcli datasets pull` keeps one mechanism rather than adding a second implementation that
could drift from it.

### Task 2: Download affordance in New Project

<read_first>
- PlatypusStudio/Sources/PlatypusStudio/NewProjectSheet.swift
</read_first>

<action>
When the selected dataset is `.downloadable`, disable Create and show a "Download (54 MB)"
button that runs `mmcli datasets pull <name>` with a progress indicator, then re-checks
availability and enables Create.

Show the size *before* the download starts — the user is agreeing to a 54 MB transfer and
should know that up front. Surface failures (offline, checksum mismatch) as the message
mmcli emitted, not a generic "failed"; the checksum case in particular needs to be
distinguishable from a network error.

Keep the sheet usable while downloading: no modal block, and a cancel that actually
terminates the subprocess.
</action>

<verify>
Drive the real UI: pick an unbundled dataset, download, confirm Create becomes enabled and
the project is created. Repeat with the network disabled to confirm the error is legible.
</verify>

## Success Criteria

- Selecting an unbundled dataset shows size and an explicit download action, never a silent stall
- Download progress is visible and cancellable
- Offline and checksum failures produce distinguishable, actionable messages
- Bundled datasets show no download affordance at all
