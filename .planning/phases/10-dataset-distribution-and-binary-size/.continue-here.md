# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Both were discovered through actual failure in this session,
> in my own output, and both were caught only by an audit or by running the real artifact.

- [ ] CONSTRAINT: **Never write a fact you have not resolved.** A commit SHA (`d9e4a1f`) was
      written into `10-09-SUMMARY.md` for a commit that does not exist. Mitigation: before
      committing any document containing a SHA, path, or measured figure, resolve it —
      `git cat-file -t <sha>`, `test -e <path>`, re-run the measurement. Not "recall it
      carefully". Resolve it.
- [ ] CONSTRAINT: **A test that simulates a code path does not test it.** The regression test
      guarding the cache side-effect called `cache_entry_size()` in a loop instead of invoking
      the CLI. It passed while the shipped binary still had the bug, because `datasets list`
      also goes through `_resolve_dataset_zip()`, which had its own copy of the defect.
      Mitigation: for any guard against a user-visible behaviour, invoke the real entry point
      (subprocess or built binary), and mutation-test it — reintroduce the bug and watch the
      test fail — before believing it.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Fabricated identifier | A commit SHA was written into a SUMMARY without being resolved; the object did not exist. Found by a traceability audit, not by review. | blocking | Resolve every SHA/path/figure against the system before committing a document. See `unplanned-work.md` §"Audit note". |
| Simulated path passes as tested | A regression test exercised helper functions resembling the real code path rather than the path itself, and passed against a binary that still had the bug. | blocking | Drive the real entry point, then mutation-test: reintroduce the defect and confirm the test goes red. |
| Partial fix declared complete | `cache_entry_path` was fixed while `_resolve_dataset_zip` kept the same defect. Only running the rebuilt binary revealed it. | advisory | After fixing a shared-helper bug, grep for every other caller of that helper before claiming the fix. |
| Fixture that could pass vacuously | The CI stand-in fixture overrode registry digests and sizes; `TestRegistryInvariants` then compared the registry against the fixture. It failed loudly here, but written the other way round it would have passed while asserting nothing. | advisory | Any fixture that patches the data under test must exclude the tests that assert on that data. |
| Availability declared from a too-short probe | ollama was reported "missing" from a 2-second curl timeout while the server was running with 24 models, which silently degraded a cross-AI review to a single reviewer. | advisory | Distinguish "did not answer in N seconds" from "absent"; re-probe before reporting a capability unavailable. |
